# KDP Publishing Execution Rules

## 1. 3D High-End Graphics Protocol
- Never generate flat, plain 2D vector drawings for Amazon A+ content or cover presentations.
- Always implement rich 3D isometric perspectives, layered gradients, realistic device/book mockups, and glassmorphic card designs.

## 2. Zero-Bleed Cover Geometry
- Calculate spine width using $\text{PageCount} \times 0.002252$ inches.
- Enforce a 250px safe barrier between the rightmost edge of the back-cover text and the start of the spine.
- Centered spine text inside spine boundaries.

## 3. SEO & Compliance Guardrails
- Title & Subtitle under 200 characters.
- 7 backend keyword slots strictly under 50 bytes each, no competitor brands, no trademark symbols.
- Nominative fair use disclaimer on copyright page and back covers.

## 4. Language Policy
- All conversational explanations and workflow outputs must be written in Telugu (తెలుగు).
