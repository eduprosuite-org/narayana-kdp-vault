## ?? Step-by-Step Publishing Guide

### 1. Compile the Interior PDF in Overleaf:
1. Open [Overleaf.com](https://www.overleaf.com/) and create a **Blank Project**.
2. Copy and paste the entire content of `Volume_1_All_In_One_Manuscript.tex` into `main.tex`.
3. Click **Recompile** and download the PDF.
4. Upload this PDF to Amazon KDP as your **6" x 9" Paperback Interior (No-Bleed, Black & White with White Paper)**.

### 2. Compile the Full-Wrap Cover:
1. In Overleaf or local LaTeX, compile `kdp_cover_6x9_fullwrap.tex`.
2. Download the resulting PDF and upload it to Amazon KDP as your **Paperback Cover PDF**.

### 3. Setup Metadata on Amazon KDP:
1. Copy the Title, Subtitle, and 7 Search Keywords from `KDP_Publishing_Package.md`.
2. Copy the HTML code from `kdp_description_raw.html` into the Book Description box.
3. Select the 3 recommended categories:
   * *Young Adult Nonfiction > School & Education > Test Preparation*
   * *Science & Math > Mathematics > Applied > Probability & Statistics*
   * *Education & Teaching > Schools & Teaching > Secondary Education*

### 4. Deploy the Free Companion to GitHub Pages:
1. Create a GitHub repository named `ap-stats-score5-blueprint`.
2. Upload the files inside `web_companion_portal/` (`index.html`, `styles.css`, `app.js`).
3. Enable GitHub Pages under **Repository Settings > Pages > Deploy from Branch (main)**.
4. Your companion web portal will be live at `https://eduprosuite-org.github.io/ap-stats-score5-blueprint/`.
