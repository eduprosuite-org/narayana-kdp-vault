## 7. Python Pillow 300 DPI Full-Wrap Generation Script

*Use the Python code below to generate a pixel-perfect 300 DPI full-wrap raster template:*

```python
from PIL import Image, ImageDraw, ImageFont

# 300 DPI Calculations for 100-page 6x9 White Paper Paperback
DPI = 300
PAGE_WIDTH_IN = 6.0
PAGE_HEIGHT_IN = 9.0
BLEED_IN = 0.125
SPINE_WIDTH_IN = 100 * 0.002252  # 0.2252 in

TOTAL_WIDTH_PX = int(round((PAGE_WIDTH_IN * 2 + SPINE_WIDTH_IN + BLEED_IN * 2) * DPI))  # 3743 px
TOTAL_HEIGHT_PX = int(round((PAGE_HEIGHT_IN + BLEED_IN * 2) * DPI))                     # 2775 px

# Create Canvas (RGB 300 DPI)
img = Image.new("RGB", (TOTAL_WIDTH_PX, TOTAL_HEIGHT_PX), color="#0B1120")
draw = ImageDraw.Draw(img)

# Spine Coordinates
spine_start_x = int(round((BLEED_IN + PAGE_WIDTH_IN) * DPI))
spine_end_x = int(round((BLEED_IN + PAGE_WIDTH_IN + SPINE_WIDTH_IN) * DPI))

# Draw Spine Guide Lines
draw.line([(spine_start_x, 0), (spine_start_x, TOTAL_HEIGHT_PX)], fill="#06B6D4", width=2)
draw.line([(spine_end_x, 0), (spine_end_x, TOTAL_HEIGHT_PX)], fill="#06B6D4", width=2)

# Draw Barcode Exclusion Zone on Back Cover (2.0" x 1.2")
barcode_x1 = int(round(3.875 * DPI))
barcode_y1 = int(round((9.25 - 1.575) * DPI))
barcode_x2 = int(round(5.875 * DPI))
barcode_y2 = int(round((9.25 - 0.375) * DPI))
draw.rectangle([barcode_x1, barcode_y1, barcode_x2, barcode_y2], fill="#FFFFFF", outline="#94A3B8")

img.save("kdp_cover_300dpi_master_template.png", dpi=(300, 300))
print(f"Generated KDP Cover Template: {TOTAL_WIDTH_PX}x{TOTAL_HEIGHT_PX} px at 300 DPI")
```
